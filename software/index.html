What it does

Every day, without anyone touching it, the pipeline writes an original short story, narrates it, adds word-by-word captions and matching stock footage, and uploads the finished video to YouTube Shorts.

How it's built

  • The Groq LLM API writes the story and the search keywords for the footage.
  • Neural text-to-speech returns word-level timings, which become captions synced to each spoken word. The run stops if timings come back empty, so a broken video never ships.
  • The Pexels API supplies enough background clips to cover the narration, and ffmpeg assembles the vertical video.
  • The YouTube Data API uploads with OAuth. GitHub Actions runs it on a daily schedule with every key kept in encrypted secrets.

HR to identity sync

Client work · PowerShell

3,170
employee records processed per full sync
PowerShellREST APIsMicrosoft GraphOAuth

Problem

Purchasing roles had to be changed by hand whenever someone was hired, changed jobs, or left, so access depended on a ticket getting filed and worked.

What I built

  • A sync that pulls the roster from the HR system's REST API and maps each employee to Entra ID security groups by job title, employment status, and supervisor.
  • Reconciliation on every run: people who join, move, or leave are added, switched, or removed, so group membership matches the HR record.
  • App-only Microsoft Graph auth through a dedicated app registration, credentials kept out of the code, retry with backoff on throttling and server errors, and log rotation.

Result

Joiners, movers, and leavers are handled by the sync instead of tickets, so purchasing access stays in step with HR.

What it does

A cross-platform app where people look up a license plate by state and number, then read and post comments with photos. It's in progress, and the Android build runs.

How it's built

  • MVVM with CommunityToolkit.Mvvm and dependency injection. Models, services, and view models live in a separate library that builds without the mobile SDKs.
  • Firebase Auth with native Google Sign-In, Firestore, and Storage, with security rules that let people write only their own data.
  • On-device OCR that reads the plate number from a photo and fills it in.
  • I traced a sign-in crash to a version mismatch between two Firebase plugin packages by decompiling them, then replaced the plugin with native sign-in.
